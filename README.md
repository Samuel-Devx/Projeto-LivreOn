#  LivreOn

> Sistema de gerenciamento para livrarias — cadastre, consulte e gerencie livros e clientes com praticidade.

---

##  Sobre o Projeto

O **LivreOn** é um sistema desktop voltado para o gerenciamento de livrarias. Desenvolvido em Java com o auxílio do Lombok para redução de boilerplate e MySQL para persistência de dados, o projeto oferece uma estrutura organizada para controlar o catálogo de livros e o relacionamento com clientes.

A aplicação segue o padrão de pacotes `br.com.livreon`, com separação clara entre as camadas de modelo, repositório e serviço.

---

##  Funcionalidades

-  Cadastro e listagem de livros
-  Cadastro e listagem de clientes
-  Busca por título, autor ou categoria
-  Remoção e atualização de registros
- Persistência de dados com MySQL

---


### Pré-requisitos

- Java >= 17
- MySQL >= 8.0
- Maven ou IDE com suporte a Java (IntelliJ IDEA recomendado)
- Lombok configurado na IDE


## Tecnologias Utilizadas

- **Java** — Linguagem principal do projeto
- **Lombok** — Redução de código boilerplate (getters, setters, construtores)
- **MySQL** — Banco de dados relacional para persistência
- **IntelliJ IDEA** — IDE utilizada no desenvolvimento
